# ITS Intac Solution

Next.js + Tailwind CSS corporate website scaffold for ITS Intac Solution.

## Setup

1. Install dependencies
   ```bash
   npm install
   ```
2. Run the development server
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000

## Fonts

Headings use Poppins, body text uses Inter via Google Fonts.
